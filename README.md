# 向远 · 生涯规划

一个面向高校学生与应届生的开源生涯规划网站。把教育背景、个人意愿、家庭期待和实践经历整理成可解释的方向建议、简历准备清单与行动计划。

本项目使用 **MIT 许可证**。当前版本是可独立运行的浏览器应用，没有账号服务、后端、AI 接口或实时招聘与招生数据库。

## 可以做什么

- **建立个人档案**：填写教育背景、专业、技能与兴趣、目标城市、预算、实习与项目经历，以及求职常见联系和到岗信息。
- **比较三条路径**：求职就业、国内升学、海外升学。展示本地规则得出的参考分、建议依据、准备缺口和下一步。
- **探索具体职业方向**：依据专业、兴趣、技能与实习岗位提供最多三个职业探索起点，用小实验检验真实感受；无匹配线索时明确展示探索示例。
- **分别表达个人与家庭意愿**：调整意愿权重，识别需要沟通的分歧，保留个人决定权。
- **准备简历**：检查常见企业筛选字段，复制或下载基于已填写资料生成的文本简历。
- **执行行动计划**：按周查看任务、标记完成并筛选待办事项。
- **查看官方资源**：访问就业、研招、学历认证和留学相关官方平台，阅读准备指南。
- **管理自己的数据**：在当前浏览器保存档案与行动进度，导出规划，或清除个人数据并恢复示例。

首次打开会展示虚构示例档案，方便了解流程；示例并非真实用户，也不是你的实际背景。可以创建自己的档案后重新生成建议。

## 本地运行

建议使用 **Node.js 24、npm 11**。无需 API Key、数据库或环境变量。

```sh
git clone https://github.com/h4jt49ybz2-stack/career-planning-website.git
cd career-planning-website
npm ci
npm run dev
```

开发服务器默认使用 `5173` 端口；实际地址以终端输出为准。开发服务会监听所有网卡，在共享或公网环境中请通过受控访问方式使用。

```sh
npm test            # 运行规划规则的单元测试
npm run typecheck   # TypeScript 类型检查
npm run build       # 类型检查并生成 dist/ 静态产物
npm run preview     # 本地检查构建产物，不是生产部署服务
npm run test:e2e    # 浏览器端到端测试
```

端到端测试会优先使用 `/usr/bin/chromium`，也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定本地 Chromium。没有浏览器时先运行 `npx playwright install chromium`；Linux 可能需要按 Playwright 文档安装浏览器系统依赖。

技术栈：React 19、TypeScript、Vite 6、Lucide 图标与 Vitest。

## 部署

`npm run build` 后，可将 `dist/` 部署到支持静态文件的服务，例如 GitHub Pages、Cloudflare Pages 或自己的 Web 服务器。Vite 已配置相对资源路径 `base: './'`，适合根目录或仓库子目录；页面导航使用 URL hash。

仓库的 CI 会执行安装、测试与构建，**不会自动发布网站**。本说明不表示任何线上站点已经部署，也不需要把个人档案提交到仓库。

## 隐私与数据

档案与任务状态保存在当前浏览器的 `localStorage` 中，规划计算也在浏览器内完成；本项目不将档案发送到服务器或 AI 服务，不跨设备同步。页面资源加载完成后，核心功能无需联网；主动访问官方外链仍需联网。

- 本地存储不等于加密保险箱，同一浏览器的其他使用者可能看到已保存资料。建议在个人设备上使用，离开公共设备前清除数据。
- 清理浏览器数据、更换浏览器或设备会导致本地资料无法继续使用。需要保留时请先导出规划或简历；导出文件可能包含联系方式，请自行妥善保存。
- 不需要填写身份证号、民族、婚育状况等信息；这些信息不参与方向建议。
- 提交 issue、截图、测试数据或代码时，请勿包含真实联系方式、家庭隐私、简历或密钥。

## 建议的边界

参考分来自可查看的规则，**不是录取率、就业成功率或专业测评结论**。档案缺项会影响建议的完整性，任何路径都需要继续核实具体条件。

当前 GPA 与语言信息只检查是否提供相关记录，不校准计分制度、不验证考试成绩。预算参考档位尚未区分国家和学制。具体职业探索采用有限关键词，不因学校名称、学历层次或家庭意见排除任何职业；没有覆盖全部专业和行业。

不同公司的必填字段和招聘流程不同；学校的招生资格、语言要求、费用与截止时间也可能变化。请以目标公司和学校当年的官方说明为准。家庭偏好仅用于辅助沟通，不应替代本人意愿。

目前尚未提供高中选科与高考志愿填报、实时院校匹配、在线岗位申请、云端同步或 AI 咨询功能。
